# 💍 페이지시스터즈(PageSisters) 감성 모바일 청첩장

감각적인 웨딩 매거진 & 화보 포스터 스타일을 모티브로 제작된 프리미엄 반응형 모바일 청첩장 웹사이트입니다.  
사용자분의 웨딩 사진(6장)을 웹 성능에 최적화하여 탑재하였으며, 모바일과 데스크톱 어디서나 우아하고 부드럽게 작동합니다.

---

## ✨ 핵심 기능 및 디자인 포인트

1. **에디토리얼 & 매거진 스타일 히어로 커버 (PageSisters Editorial Style)**
   - 감각적인 영문 세리프 타이포그래피 (`Cormorant Garamond`) & 단아한 한글 명조 (`Gowun Batang`)
   - 감성적인 웨딩 메인 사진과 시네마틱 오버레이
   - 스크롤 유도 인디케이터 라인 애니메이션

2. **실시간 3가지 감성 테마 스위처**
   - 🌸 **Editorial Cream (기본)**: 따뜻한 캐시미어 크림 & 로즈우드 톤
   - 🌿 **Modern Olive**: 차분하고 싱그러운 세이지 그린 & 내추럴 올리브 톤
   - 🕊️ **Classic Navy**: 단정하고 기품 있는 딥 네이비 & 앤틱 톤

3. **내장 웨딩 BGM 엔진 (Pachelbel's Canon)**
   - Web Audio API 기반의 서정적인 피아노 사운드 합성 엔진 내장 (외부 mp3 링크 끊김 걱정 없음)
   - 모바일 제약을 고려한 원클릭 ON/OFF 플로팅 LP 디스크 애니메이션

4. **소중한 분들을 위한 모시는 글 & 연락처 팝업**
   - 따뜻한 서정적 초대 문구
   - 양가 부모님 및 신랑·신부 성함 표시
   - 클릭 시 하단에서 부드럽게 올라오는 '축하 연락하기' 바텀 시트 (신랑, 신부, 혼주 원클릭 전화걸기 `tel:` / 문자보내기 `sms:`)

5. **2027년 캘린더 & 실시간 D-Day 카운트다운**
   - 해당 월의 달력을 자동 렌더링하고 예식 당일 하트/원형 링 하이라이트
   - 일, 시간, 분, 초 단위 실시간 카운트다운 배너

6. **매거진 모자이크 갤러리 & 풀스크린 라이트박스**
   - 실제 촬영 사진 6장을 감각적인 그리드로 배치
   - 사진 탭 시 전체화면 라이트박스 팝업 (모바일 터치 스와이프 제스처, 좌우 화살표, 확대/축소 지원)
   - 2~3MB 원본 사진을 200~300KB로 압축한 웹 최적화 이미지 탑재로 0.1초 초고속 로딩

7. **오시는 길 & 3대 네비게이션 앱 연동**
   - 상세 주소 복사 버튼 & 복사 완료 토스트 알림
   - 카카오맵(Kakao Map), 네이버 지도(Naver Map), 티맵(T map) 원클릭 길안내 바로가기
   - 지하철, 버스, 주차/연회장 상세 안내 카드

8. **마음 전하실 곳 (축의금 계좌 복사)**
   - 신랑측 / 신부측 계좌번호 아코디언 토글
   - 원클릭 계좌번호 복사 & 부드러운 햅틱 감성 토스트

9. **참석 여부 전달 (RSVP)**
   - 신랑측/신부측 구분, 참석 여부, 식사 여부, 동행 인원수, 축하 메모 입력 폼
   - 로컬스토리지에 안전하게 기록되어 언제든 확인 가능

10. **축하 방명록 (Guestbook)**
    - 하객들이 남기는 축하 메시지 등록 및 실시간 피드
    - 로컬스토리지 영구 보관 지원

11. **공유하기**
    - 카카오톡 및 모바일 네이티브 공유 (`navigator.share`)
    - 청첩장 링크 원클릭 복사

## 🛠️ 정보 수정 가이드 (`js/config.js`)

신랑, 신부님의 성함, 예식 일시, 장소, 계좌번호 등 모든 정보는 `js/config.js` 파일 하나에서 아주 쉽게 수정하실 수 있습니다.

```javascript
// js/config.js 예시
const WEDDING_CONFIG = {
  groom: {
    name: "진경민",
    englishName: "Kyungmin Jin",
    phone: "010-1234-5678",
    ...
  },
  bride: {
    name: "박소현",
    englishName: "Sujin Lee",
    phone: "010-8765-4321",
    ...
  },
  weddingDate: {
    year: 2027,
    month: 5,
    day: 22,
    dayOfWeek: "토요일",
    time: "낮 12시 30분",
    isoString: "2027-05-22T12:30:00+09:00"
  },
  venue: {
    name: "더 라움 (THE RAUM)",
    hall: "4F 체임버홀",
    address: "서울특별시 강남구 언주로 564",
    ...
  }
};
```

## 🚀 사이트 열어보기 및 실행 방법

### 방법 1. 브라우저에서 바로 열기
별도의 설치나 서버 실행 없이 `index.html` 파일을 더블클릭하거나 터미널에서 다음 명령어로 즉시 열 수 있습니다:
```bash
open index.html
```

### 방법 2. 로컬 웹 서버 실행 (Node.js)
```bash
node server.js
# 브라우저에서 http://localhost:3000 접속
```

## 🌐 무료 배포 방법 (하객들에게 링크 보내기)

1. **GitHub Pages (추천)**:
   - 본 리포지토리를 GitHub에 업로드한 뒤, `Settings > Pages`에서 Branch를 `main`으로 설정하면 `https://<아이디>.github.io/<리포지토리명>` 주소로 즉시 전 세계 어디서든 접속 가능합니다.
2. **Vercel / Netlify**:
   - `모청` 폴더를 Vercel 또는 Netlify에 드래그 & 드롭만 하면 30초 만에 나만의 커스텀 URL이 생성됩니다.
